# 1. Product vision

SHIFT/MARKET — не обычный BI-dashboard.

Это:

> AI Commerce Intelligence Platform

для ответа на четыре вопроса:

1. Что происходит с продажами?
2. Почему это происходит?
3. Что нужно сделать?
4. Какой результат можно ожидать от этого действия?

Главный product loop:

DATA → ANALYSIS → DIAGNOSIS → HYPOTHESIS → ACTION → RESULT → LEARNING

Пользователь не должен самостоятельно изучать десятки графиков.

Система должна превращать данные в конкретные бизнес-рекомендации.

Пример:

Плохо:

> ROAS снизился на 18%.

Хорошо:

> ROAS снизился на 18%. Основной фактор — рост CPC на 21% при стабильной конверсии. При этом SKU имеет conversion rate выше среднего по аккаунту.
>
> Рекомендация: не увеличивать общий бюджет. Перераспределить бюджет на SKU X и снизить ставку для SKU Y.
>
> Ожидаемый потенциал: +8–12% revenue при сохранении текущего бюджета.

Используется для:

* deterministic business logic;
* thresholds;
* benchmarks;

# 27. Mock data

Для MVP создай realistic mock dataset.

Не используй случайные числа.

Данные должны быть логически связаны.

Например:

* увеличение advertising spend может приводить к увеличению clicks;
* clicks × conversion = orders;
* orders × AOV ≈ revenue;
* CPC = spend / clicks;
* CPO = spend / orders;
* ROAS = revenue / spend.

Создай минимум:

* 30 SKU;
* 90 дней sales history;
* 30 дней advertising history;
* 10 competitors;
* 10 external campaigns/events;
* price history;
* inventory history.

Используй реалистичные сезонные колебания.

# 28. Analytics calculations

Все базовые метрики должны считаться программно.

Не хардкодить значения в UI.

Формулы:

```text
CTR = Clicks / Impressions

CPC = Spend / Clicks

CVR = Orders / Clicks

CPO = Spend / Orders

ROAS = Revenue / Spend

AOV = Revenue / Orders

Revenue per click = Revenue / Clicks
```

Добавь защиту от division by zero.

# 42. Acceptance criteria

MVP считается успешным, если:

### Dashboard

* пользователь понимает состояние бизнеса за 5 секунд;
* есть AI Executive Summary;
* есть Top Actions.

### Advertising

* видны основные рекламные KPI;
* placement comparison работает;
* recommendation engine формирует рекомендации;
* есть AI diagnosis.

### Sales

* есть динамика продаж;
* есть SKU analysis;
* есть opportunity matrix.

### External media

* можно создавать campaign events;
* события отображаются на timeline;
* можно сравнивать before/during/after;
* считается estimated incremental impact.

### Competitors

* отображается конкурентная динамика;
* есть competitive pressure;
* есть tactical recommendations.

### Content

* есть content score;
* есть AI assessment;
* есть конкретные рекомендации.

### Integrations

* есть Kaspi connector abstraction;
* есть Redstat connector abstraction;
* есть demo connectors;
* secrets безопасны.

### AI

* AI не придумывает данные;
* AI использует только доступный dataset;
* каждая рекомендация имеет confidence;
* при недостатке данных AI сообщает об этом.

# 43. Очень важный product principle

Не превращай приложение в "ещё один dashboard".

Каждый экран должен отвечать:

> SO WHAT?

То есть после каждой аналитики пользователь должен понимать:

**Что произошло?**

↓

**Почему?**

↓

**Что делать?**

↓

**Какой потенциальный эффект?**

↓

**Насколько мы уверены?**

Именно это является главным отличием SHIFT/MARKET от обычных marketplace analytics tools.
